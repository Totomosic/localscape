# Duo Nylocas Ranger client plugin

This plugin has been removed from the custom client. Rebuild with
`./dev build-client` and relaunch the client to load the change.

The ranger strategy remains available in the
[headless Nylocas simulation runner](nylocas-simulations.md). Its
[strategy hierarchy](nylocas-duo-ranger-strategy.md) and
[wave guide](nylocas-duo-ranger-waves.md) document the server agent.
