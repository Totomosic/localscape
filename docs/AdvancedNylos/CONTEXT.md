# Advanced Nylos

This library is a transcription of information from a discord server focusing on helping players improve their average and peak nylocas boss from spawn times from 3:1x -> 3:0x.

## Structure

Each folder represents a category, General contains useful information both roles. MageInfo contains mage role specific information. RangeInfo contains range role specific information.

Each markdown file represents a discord channel and focuses on a particular topic. Some channels focus on specific wave (eg. [5-8](RangeInfo/5-8.md)) and some focus on key concepts (eg. [transition](General/transition.md))

## Accuracy

The information in this library is created by one individual and therefore is very opinionated and subjective. Do not treat information as an absolute source of truth. When reading information you should compare it against your own experience and evaluate, also be prepared to be open to new ideas and concepts that will help you improve.

Some of the information is outdated. For example, "sang" refers to the old 4 tick mage weapon that players would bring, this has been entirely replaced with 3 tick eye of ayak or zorya's tome. In general, "sang" can be replaced with the 3 tick mage weapon in all situations.
