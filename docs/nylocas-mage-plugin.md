# Duo Nylocas Mage client plugin

This plugin has been removed from the custom client. Rebuild with
`./dev build-client` and relaunch the client to load the change.

The mage strategy remains available in the
[headless Nylocas simulation runner](nylocas-simulations.md). Its
[strategy hierarchy](nylocas-duo-mage-strategy.md) and
[wave guide](nylocas-duo-mage-waves.md) document the server agent.
